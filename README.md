# AI Prompt Ideas – Portfolio Website

A simple **static website** built with HTML and CSS that showcases curated prompt ideas for working with Generative AI tools.

**Author:** Mahamed Muhumed  
**GitHub:** https://github.com/mahamedmuhumed9100-bit

## Features

- Responsive layout using pure HTML & CSS
- Cards displaying different prompt categories:
  - Coding
  - Learning
  - Productivity
- Clean, modern dark UI style

## Technologies Used

- HTML5
- CSS3 (no frameworks)

## How to View

- Open `index.html` in any web browser.
- Or host it using GitHub Pages.
