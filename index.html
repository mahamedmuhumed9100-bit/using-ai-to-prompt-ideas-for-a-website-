Curated Prompt Examples

Below are some example prompts I designed for working with large language models and generative AI tools.

Coding

Refactor Legacy Code

Prompt designed to improve old code while keeping the same behaviour.

"Here is a C# method from an old project. Refactor it to improve readability and maintainability. Add comments explaining the logic and suggest any edge cases I should test for: ```csharp // paste method here ```"
Learning

Explain Concepts Simply

Prompt to break down complex technical topics for beginners.

"Explain how a relational database works to a beginner. Use simple language and a real-life example, then give 5 practice questions."
Productivity

Study Plan Generator

Prompt to create structured revision plans for exams or coursework.

"Create a 2-week revision plan for my T-Level Digital Production and Development exam. Include daily tasks, practice questions and recap days."
